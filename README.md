# Cải tiến UI E-commerce: Hasaki.vn

## 1. Giới thiệu
Dự án tập trung tinh gọn thiết kế thẻ sản phẩm (Product Card) của trang chủ Hasaki nhằm giảm thiểu tình trạng rối mắt do lạm dụng nhãn khuyến mãi, giúp người dùng tập trung vào sản phẩm.

## 2. Website tham khảo
- Tên website: Hasaki Beauty & Clinic
- URL: https://hasaki.vn
- Khu vực đã khảo sát: Trang chủ, Danh mục, Chi tiết SP, Tìm kiếm, Giỏ hàng.

## 3. Chức năng
- Hiển thị danh sách thẻ sản phẩm dạng lưới (Grid).
- Thẻ sản phẩm tối giản: Hình ảnh, Tên, Giá bán/Giá gốc, Nhãn giảm giá tinh gọn, Nút Mua hàng.
- Bố cục Responsive tự co giãn trên máy tính và điện thoại.

## 4. Công nghệ
- HTML5
- CSS3 (Flexbox & CSS Grid)

## 5. Cách chạy
Mở file `index.html` bằng trình duyệt web bất kỳ.

## 6. Cải tiến đã thực hiện
- Vấn đề ban đầu: Lưới sản phẩm trang chủ hiển thị quá nhiều nhãn đè lên nhau che khuất hình ảnh.
- Cải tiến: Áp dụng CSS Grid để chia lại khoảng cách; chuẩn hóa font chữ; chuyển nhãn giảm giá thành một badge nhỏ góc phải; thêm hiệu ứng hover.

## 7. Hỗ trợ từ AI
- AI hỗ trợ phân tích UX/UI 5 khu vực website.
- AI đề xuất bộ khung HTML/CSS responsive.
- Tôi đã kiểm tra mã, tinh chỉnh mã màu nhận diện thương hiệu Hasaki và cập nhật dữ liệu mẫu.
